# Assignment 2 – Java Collections and Generics (CO2)

**Course:** Programming in Java  
**Coverage:** Strings and StringBuilder, Collections Framework (List, Queue, Deque, PriorityQueue, Set and Map), hashCode–equals, Generics, Comparable/Comparator and Collections utilities.  
**Total:** 50 marks | **Questions:** Q1–Q7

## Task folders
- Task01 – String, StringBuilder and StringBuffer performance
- Task02 – ArrayList, LinkedList and ArrayDeque comparison
- Task03 – HashSet and hashCode–equals contract
- Task04 – HashMap, TreeMap and LinkedHashMap inventory
- Task05 – Generic sports leaderboard and comparator
- Task06 – PriorityQueue emergency triage
- Task07 – Diagnose, redesign and validate

Each task folder contains a README and Java source under `src/`.

## Requirements
Java 17 or later; no external libraries required.

## Compile and run
Open the relevant task's `src` folder:
```bash
javac FileName.java
java PublicClassName
```
Use the exact filename and class name shown in that task README.
