# Assignment 4 – CO4: Event-Driven GUI Design

Six tasks covering GUI design review, hospital appointments, responsive library search, drawing-pad event repair, four event-listener styles, and a Swing/JDBC campus event registration system.

Each Task folder contains Java source and a README. Task 6 includes the MySQL schema. Use JDK 17+. Compile from each src folder with javac *.java and run the public class named in that task README.

Task 3 requires screenshots at three window sizes; Task 4 requires minimize/restore testing; Task 5 requires valid and invalid conversion screenshots; Task 6 requires normal, invalid and duplicate-registration tests. Run the programs locally and add genuine screenshots before submission. Task 6 needs MySQL and Connector/J.
