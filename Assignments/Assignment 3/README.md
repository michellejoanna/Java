# Assignment 3 – Exception Handling and Multithreading (CO3)

**Mode:** Pair work – 2 students | **Total:** 50 marks | **Questions:** Q1–Q7

## Coverage
Exception hierarchy, checked/unchecked exceptions, try/catch/finally, throw/throws, custom exceptions, chaining and propagation, try-with-resources, debugging, thread life cycle, Thread/Runnable, synchronization, deadlock, inter-thread communication, ExecutorService, Callable/Future and concurrent collections.

## Task folders
- Task01 – Bank ATM exception handling
- Task02 – Examination portal user-defined exceptions and chaining
- Task03 – Resource safety: manual close and try-with-resources
- Task04 – Thread creation and life cycle
- Task05 – Cinema seat-booking race condition and synchronization
- Task06 – Wallet deadlock prevention and producer-consumer TokenCounter
- Task07 – Concurrent fault-tolerant result processor

Each task includes a README and Java source under src. Use Java 11 or later; follow each task README for the exact compile/run command.
